# 线框图与视觉稿

打开 [index.html](index.html) 查看设计图册。无需安装依赖或连接网络，可直接双击打开。

## 使用方式

- 「视觉稿 / 线框图」切换所有页面的呈现方式，页面内容保持一致。
- 按模块或关键词筛选；点击页面标题或「放大查看」阅读完整页面和设计注释。
- 放大视图支持上一页、下一页和键盘方向键；Escape 关闭。
- 「流程」入口将页面串成游客发帖、注册加入群、恋爱开通及活动报名四条路径。这里只导航设计稿，不执行真实业务操作。
- 图册顶部可切换 iOS / Android 系统样式；这是外观对照，不代表两端已开发。

## 视觉方向

暂用展示名「在日·同好」，不是已确定的产品名称。面向在日华人的日常交流，浅蓝灰底、白色内容、深蓝绿操作色，使用地区与兴趣标签表达共同生活圈。恋爱页面采用低饱和莓红辅助色，仍共用组件。

| Token | 值 | 用途 |
|---|---|---|
| ink | #163E43 | 标题、主文字 |
| primary | #086D72 | 主操作、当前导航 |
| canvas | #EFF5F7 | 手机页面背景 |
| surface | #FFFFFF | 卡片与输入 |
| muted | #597078 | 辅助文字 |
| dating | #9B4968 | 恋爱操作和主题强调 |

字号层级：手机页标题 24px、段落 14px、辅助 12px；展示标题采用中文宋体作少量强调，手机正文使用本机中文无衬线字体。手机画板基准为 390 × 844 CSS px，图册中缩小展示；完整稿允许滚动，避免将长表单挤入一屏。

## 内容范围

覆盖交互方案全部 27 个手机页面 ID，包含注册验证码、审核/报名/配对等变体、通用状态及管理后台。页面映射与备注包含在图册中。

共 47 张稿件，每张提供视觉与线框两种版本；`exports/visual/` 与 `exports/wireframe/` 按页面 ID 保存完整 PNG，`exports/*-sheet-*.png` 是便于对照的手机页面总览。后台目前提供窄幅内容布局，正式后台桌面侧栏与宽屏表格在后台开发阶段细化。

`exports/verification.json` 保存浏览器检查摘要。`tools/render.cjs` 可使用 Playwright 与本机 Chrome 重新检查、导出；通过环境变量 `DESIGN_PLAYWRIGHT_PATH` 和 `DESIGN_BROWSER_PATH` 指定工具位置。只浏览图册不需要这些工具。

这些是可审阅的设计稿，不是已接通后端的 App。按钮外观用于表达操作；放大、切换、筛选和流程导航可实际使用，真实发布、上传、登录、聊天、报名及审核不执行。人物为示意插画，内容与数据均为虚构示例。图片配额及其他待确认规则沿用评审建议。

后续依据审阅结果细化视觉与组件，再转换为 React Native 页面。年龄自我声明不展示认证徽章；游客内容管理依赖本机凭证，不能保证跨设备恢复。
