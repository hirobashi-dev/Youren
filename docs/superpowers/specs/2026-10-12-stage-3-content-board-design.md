# 第三阶段：留言板与图片审核设计

## 文档状态

状态：用户已确认设计方向，本文待用户审阅后再编写实施计划。

本设计基于既有产品、数据库/API、技术与移动端交互方案，定义第三阶段的范围和实现边界。旧文档中尚未确认的建议以本文和已确认规则为准；既有详细设计中已确认的约束继续有效。

## 1. 目标与范围

第三阶段交付公开留言板的帖子、图文回复、图片上传、地区与兴趣筛选、举报，以及处理待审内容和举报的最小管理后台。游客和注册用户都可参与普通公开留言板，内容只有经过人工审核后才公开。作者可管理本人内容。

端到端流程：游客或账号创建帖子/回复并上传图片；后端校验权限、文字限制、图片约束和内容状态；图片完成自动技术检查和转换；人工审核后公开或驳回；作者可编辑被驳回内容并重新提交；用户可举报有权查看的内容；公开列表立即过滤到期内容，清理任务删除到期正文、附件与缓存。

本阶段不实现 AI 内容审核、群聊、活动、恋爱资料审核、私聊内容审核、第三方存储供应商或完整运营分析。存储接口为未来 S3 适配留出边界。

## 2. 已确认的产品规则

### 2.1 文字、图片和所有权

- 帖子标题最多 60 个可见字符，正文最多 2,000 个可见字符，标题和正文均不能为空。
- 回复最多 1,000 个可见字符；回复允许仅包含图片。
- 每帖最多 9 张图片，每条回复最多 3 张图片。
- 图片最大 5,000,000 bytes；支持静态 JPEG、PNG、WebP；最多 20,000,000 个解码像素。
- 展示图最长边最多 1,920 像素，不放大较小图片；展示图目标不超过 1 MB。移除 EXIF 等元数据，原始图片不直接公开。
- 字符数按 NFC 规范化后的 Unicode 可见字符计数；超限拒绝，不静默截断。
- 游客只能凭游客凭证管理其游客身份创建的内容；注册用户只能管理自己的账号内容。接续游客内容须证明原凭证所有权，不能仅凭客户端提供的 ID 认领。

### 2.2 审核、公开和到期

- 帖子及回复创建后进入待审；待审内容和图片不出现在公开列表，也不能通过猜测媒体地址读取。
- 图片处理器的“技术处理通过”只代表格式、安全及展示图处理完成，不代表内容合规或可以公开。
- 发布决定由人工审核员作出。通过后才公开；驳回须记录理由。作者修改被驳回内容后，内容重新进入待审。
- 待审超过 72 小时触发管理提醒；内容保留在待审状态并等待人工处理，不自动驳回或删除。
- 首次公开时记录 published_at，并计算一年后的 expires_at。隐藏后恢复不重置首次公开时间或到期时间；编辑及新回复不延长既有内容期限。
- 到期过滤以服务端时间为准，在 now >= expires_at 时立即不公开；清理任务再删除正文、附件和派生缓存。父帖到期但有独立未到期回复时，可依既有数据/API规则保留占位，以访问仍有效的回复。
- 未关联至内容的上传资源在 24 小时后清理。该规则只清理孤儿上传，不影响人工待审内容。

## 3. 存储及图片处理

### 3.1 本机存储优先

第三阶段使用本机文件系统。文件根目录通过本机环境配置指定，不能写入 Git 跟踪的源代码目录或直接映射为公开静态目录。图片对象使用随机、不可猜测的键；数据库保存对象键、处理状态、用途、大小、校验摘要和必要元数据，不保存用户可控的任意路径。

后端经由媒体服务访问文件。上传、下载和查看均通过 API 的身份、所有权、内容状态与权限检查；不得暴露文件根路径、可枚举文件名或绕过权限的永久公开 URL。防止路径穿越、重复绑定、跨用户绑定、处理未完成时绑定和部分成功造成的孤儿文件。

媒体存储提供稳定的读、写、删除接口，将本机实现与业务服务隔离。未来接入 S3 时新增适配器和迁移/复制流程，不把 S3 SDK、对象 URL 或供应商特性散布到帖子业务代码。当前不创建 S3 存储桶或依赖云服务。

### 3.2 自动技术处理

1. 验证上传者、用途、上传会话和大小上限；会话有时效且不可被其他身份接管。
2. 检查实际文件签名并解码图片，不信任扩展名或客户端 MIME；拒绝损坏、动画或不支持格式。
3. 拒绝超过像素上限的文件，并限制解码时间、内存与并发，避免资源耗尽。
4. 重编码展示图、移除 EXIF 等元数据、不放大图片；原图保存在私有区并限制用途和访问权限。
5. 记录技术处理结果。失败时不把部分产物绑定到帖子，并清理临时文件。

展示内容只引用处理后的展示图。原图和处理中对象不能由客户端公开读取。文件操作可安全重试；重复请求不产生额外绑定，也不能误删其他内容的文件。

### 3.3 媒体与内容状态分离

媒体状态描述上传和文件处理生命周期，帖子/回复状态描述审核和公开生命周期。建议媒体状态：initiated → uploaded → processing → ready；失败或清理后进入 rejected、deleting、deleted 等终态。ready 仅表示媒体可供审核使用。

帖子/回复状态：pending → visible 或 rejected；已公开内容可因人工处置进入 hidden，作者可删除为 deleted，期限到达后为 expired。deleted 和 expired 不可恢复；隐藏内容恢复时仍须满足权限且未到期。

## 4. 举报与管理权限

### 4.1 举报

已登录用户或游客可举报其当前有权查看的帖子或回复。举报使用固定原因分类，可附可选说明；成功返回受理状态，不宣称内容已删除。同一幂等标识的重复提交返回已有受理结果。举报人身份和说明不公开。

### 4.2 管理审核台

最小后台包含独立登录入口、多因素验证、待审队列、待处理举报、内容及图片只读详情、通过/驳回/隐藏/恢复/删除操作、理由输入和审计记录。审核员只查看工作所需上下文；后台不展示游客凭证、邮箱、服务器文件路径或无关个人资料。

管理员身份与普通用户身份、会话和权限分离。首个管理员通过一次性本机初始化命令创建：操作者交互式提供凭据并配置第二因素；命令不内置默认用户名或密码，不在日志回显秘密，完成后不可重复创建首个管理员。后续管理员通过有权限的管理流程创建或邀请并记录审计。

按最小权限区分审核操作员和只读审计员。改变内容状态的操作须提交理由、期望版本和幂等标识；服务端验证权限和并发版本并生成一般后台用户不能修改的操作记录。超过 72 小时的待审条目显示告警，不自动改变状态。

### 4.3 可替换的审核决策

审核决策经独立接口接收内容版本、结论、理由分类及审核主体。第三阶段只配置人工决策，不调用 AI，也不依据图片自动处理结果自动发布或驳回。

以后可为同一接口增加 AI 筛查或辅助建议。实施前需另行确定供应商、图像是否离开本机、个人信息与保留规则、误判处置、人工复核和故障回退。是否允许 AI 自动作最终决定不由本设计预先授权；人工审核必须可以继续运行。

## 5. 页面和交互流程

### 5.1 移动端留言板

- 列表只展示公开且未到期的帖子，提供地区、兴趣筛选；分页顺序稳定，筛选条件由服务端验证。
- 详情展示已通过内容及展示图、回复和举报入口。待审、驳回、隐藏、删除、到期状态仅向作者展示对应说明。
- 编辑器显示文字/图片剩余上限；选图前说明格式和大小限制。上传、处理、提交、审核分步显示，不能把“已上传”呈现为“已公开”。
- 作者可查看本人内容状态，重试可重试失败，编辑被驳回内容，删除本人内容。重复提交须幂等；网络超时后先查询服务端状态。
- 游客界面说明游客身份与凭证管理；注册接续不泄漏游客和账号的关联。

### 5.2 管理端

- 待审队列按创建时间和等待时长排序，突出超过 72 小时的提醒；可筛选待审、举报及已处理项目。
- 详情展示必要上下文、展示图、所属帖子和作者展示身份，不提供原图下载作为默认操作。
- 每次处置须填写理由并确认；版本冲突时要求重新载入，不能覆盖新提交或其他审核员的决定。
- 举报处置和内容审核分别记录；处理举报本身不自动隐藏或删除内容。

## 6. 安全与失败处理

- 逐层检查作者、内容、媒体绑定关系和权限；不信任客户端传来的作者 ID、对象键、公开状态、发布时间或到期时间。
- 上传、绑定、审核、删除具备幂等和并发版本检查。多张图片绑定全有或全无；失败回滚绑定并清理孤儿对象。
- 上传接收阶段限制大小；图片解码使用受限资源，设置超时、内存和并发上限。
- 下载前重新检查内容和媒体可见状态；隐藏、驳回、删除、到期后使缓存失效，旧链接不能继续访问。
- 审计只记录必要的操作者、动作、目标、理由分类、内容版本和时间，不复制完整正文、凭证或秘密。
- 错误响应不泄漏数据库凭据、原始异常、文件路径或个人信息；可重试错误明确说明是否可能重复创建。

## 7. 验收标准

1. 游客及账号可按权限创建帖子、图文回复；文字、图片张数、字节、格式与解码像素限制在服务端生效。
2. 伪造扩展名、损坏图片、动画图片、超大图和带元数据图片被拒绝或安全转换；展示图不含 EXIF，原图不可公开读取。
3. 上传、技术处理完成和内容审核状态分开；待审内容不能从列表、详情、媒体请求或猜测地址读取。
4. 人工通过后内容可见；驳回后不公开，作者编辑后重新待审；待审超过 72 小时只告警并保留。
5. 游客凭证和账号所有权检查阻止越权编辑/删除；其他用户不能绑定、读取或删除他人媒体。
6. 举报可幂等重试；重复报告返回既有状态，报告提交不会隐式删除内容。
7. 审核操作校验权限、理由、期望版本并记录审计；版本冲突不会静默覆盖。
8. 隐藏恢复保留原到期时间；到期内容立即从列表与媒体读取中隐藏，清理可安全重试。
9. 无内容、上传失败、断网、超时、权限失效、待审、驳回和过期状态在移动端正确呈现，草稿不会因旧请求响应而丢失。
10. 一次性管理员初始化不含默认凭据，重复初始化安全失败；管理员认证、普通用户身份与角色权限隔离。
