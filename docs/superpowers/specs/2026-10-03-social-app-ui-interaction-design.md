# 在日华人交友 App 页面与交互设计

## 1. 文档范围与决策状态

依据：[产品方案](2026-10-03-social-app-design.md)、[技术方案](2026-10-03-social-app-technical-design.md)，以后者第 14、15 节最新决策为准。本文件是详细页面与交互评审稿，可作为后续线框图、视觉稿和接口设计的输入，不代表已实现页面。

已确认：中文界面、在日华人用户、iOS 与 Android、邮箱验证码注册、游客普通留言板浏览/发帖/回复/图片、兴趣/恋爱/同城活动、群聊、恋爱入口年龄勾选、默认业务保留期一年。

已确认补充：注册用户可以创建普通群聊，创建者担任群主；普通群加入无需审批；注册用户可以发布活动与普通私聊；消息和留言板内容按各自发送/发布时间保留一年。建议而未确认：四个底部导航、游客浏览群及活动概要但注册后加入、免费活动、普通私聊接收设置、邮箱验证码登录、活动修改取消细则。下面以这些默认值设计，未确认功能不得当作已授权业务规则。

年龄勾选是自我声明，不显示“年龄已认证”徽章；正式恋爱上线仍遵循技术方案的确认事项。一年起算点和例外尚未定案，页面不承诺确切删除日期。

## 2. 信息架构与导航

默认首次进入留言板，不强制注册、定位、兴趣选择或年龄弹窗。顶部允许自选地区；不申请精确定位。

| 底部入口 | 一级内容 | 主要二级页面 |
|---|---|---|
| 发现 | 兴趣交友 / 恋爱配对 / 同城活动 | 兴趣详情、群详情、恋爱开通与资料、活动详情 |
| 留言板 | 全部 / 兴趣 / 同城，最新与有回复筛选 | 搜索、帖子详情、发帖、我的发布 |
| 消息 | 聊天 / 互动通知 | 群聊、普通私聊、恋爱匹配私聊、群信息、通知详情 |
| 我的 | 游客内容或账号资料、参与记录 | 登录、编辑资料、我的群、我的活动、设置 |

游客可进入所有一级入口；需注册的操作在点击时说明原因，不强制跳走。恋爱一级只展示功能说明，未满足权限者不能预览他人恋爱资料。普通公开留言板不混入恋爱招募帖子。

底部导航切换保留列表位置和筛选。帖子详情、聊天和编辑页隐藏底部导航，提供返回。通知或分享链接打开目标时重新鉴权；目标不可见显示原因和返回入口。注册成功回到原操作，并让用户再次确认报名/加入/喜欢等有后果操作，不自动执行。

## 5. 留言板详细交互

### B01/B02 首页与搜索

卡片显示分类、标题、正文摘要、最多三张已审核缩略图、作者标识、相对时间和回复数。点卡片进入详情，点图进入图片查看器，不误触跳到作者页面。游客作者标识不可点击为跨帖个人主页；注册用户只有主动公开关联时展示账号主页。

发帖按钮固定但不遮挡内容。筛选采用底部面板，用户选择后点“应用”；提供“重置”。地区使用都道府县→市区町村，允许仅选都道府县及“不限”。首次未选地区默认不限，不根据 IP 显示用户所在地。搜索提交后更新列表，保留关键词；空结果提供清除筛选，不能伪装成网络失败。

首次加载显示骨架，下拉刷新保留当前内容；翻页失败在列表底部提供重试；空版块显示“还没有讨论，来发第一帖”。首版不将点赞作为必要交互，待确认再加入。

### B03 详情与回复

详情展示完整正文、图片和回复，默认按发布时间正序；支持引用回复，视觉嵌套最多一层，以“回复某人”表示更深关系。回复数量只统计可见回复。图片全屏可左右切换、缩放、关闭，不在照片上显示个人位置元数据。

底部输入允许游客直接发言。第一次提交前自动建立游客凭证，显示一次轻量说明：“你正在以游客身份发布。请保留本机数据，以便管理内容。”失败保留草稿，不要求注册。

自己的帖子“更多”提供删除；他人内容提供举报，注册用户可选择屏蔽。首版建议已公开帖子不提供直接编辑，使用删除后重发；待审拒绝内容可进入编辑重提。删除确认说明不可撤销，成功返回列表或保留“内容已删除”占位，避免暴露已删正文。

帖子已删除、隐藏、过期或无权限时用统一不可用页，不展示缓存正文；允许返回。发布自己的待审内容仅本人能在“我的发布”查看。

### B04/B05 编辑与图片

发帖字段：标题必填（最多 60 个可见字符）、正文必填（最多 2000 个可见字符）、分类必选、兴趣可选、地区可选；回复正文最多 1000 个可见字符，有图片时可无文字。大小限制已确认，客户端与后端使用同一规则配置，不额外引入未确认的标题最少五字限制。

图片通过系统选择器添加，选择后显示预览、删除按钮、上传进度和失败重试。已确认帖子最多九张、回复最多三张、单张 5 MB；展示版本压缩，长边不超过 1920 像素。HEIC 等格式如需转换，先在客户端转为支持格式再按服务端规则验证；转换失败给出明确提示，不静默丢图。照片选择不要求全图库授权。取消选择不影响已选内容。

发布按钮在必填合格且所选图片上传完成后启用。点击后锁定重复提交，发送同一请求标识；网络超时提示“正在确认发布结果”，查询结果后再允许重试，避免重复帖。

内容提交后区分“审核中”和“已发布”，不得在图片未审核时提示公开成功。审核未通过显示可操作原因与移除/替换入口；重新发布重新审核。离开有改动的编辑器时提示保存草稿、放弃或继续编辑。草稿保留本机，注明不保证卸载后恢复；用户删图后草稿同步去掉该引用。

B06 显示已发布、审核中、未通过、已删除记录。游客入口文案“本机发布”，无法在另一台设备凭昵称找回；注册成功后可管理已接续内容，原公开游客身份保持不变。

## 6. 邮箱注册与资料

A01 采用两步邮箱验证码流程，登录与注册共用入口。输入邮箱→发送验证码→输入验证码→登录或创建账号。账号首次创建前主动勾选服务条款和隐私政策，不预选；发送成功显示邮箱、重新发送倒计时与“修改邮箱”。输入错误不清空邮箱，验证码失败显示原因与剩余尝试提示，限流显示可重试时间。

已有账号登录时也校验游客凭证才能接续；不能仅凭同一邮箱认领内容。接续成功提示“本机发布内容已保留”，默认不改变公开展示身份。接续失败不阻止登录，说明原内容仍需原凭证，并提供稍后重试，不声称已接续。

注册后 A02 昵称必填，头像、兴趣、地区和简介可稍后填写。加入群、活动或开启恋爱时只补充该操作必要资料，不在首次浏览前要求完整填写。邮箱始终不公开。

用户在加入群、报名等入口触发注册：显示“注册后可以加入群聊”等具体说明，提供“继续浏览”。成功返回原页，重新显示确认操作；年龄勾选不得混入通用注册协议。

## 7. 兴趣交友与群聊

D01 提供兴趣主题和相关讨论、群列表，不以用户照片为主。D02 将“讨论”和“群聊”分开，点讨论进入留言板，点群进入 G01。兴趣选择可在我的中修改，不强制在冷启动完成。

G01 展示群名称、主题、介绍、人数、群规、加入方式。游客可查看公开概要，不能查看成员名单、消息或准确活动地点。加入按钮按状态显示“注册后加入群聊”“加入群聊”“正在加入”“进入群聊”“暂不可加入”，不显示入群申请或等待审批。注册后回原页再次确认；服务端写入成员成功后展示加入成功，再进入群聊。失败留在原页，重复操作不重复占名额。

G04 从兴趣群列表与我的群聊的“创建群聊”进入。游客点击该入口先注册，注册用户直接填写名称、兴趣主题、群介绍及地区；群规可填写。创建前说明“创建后你将成为群主”。提交时显示创建中并阻止重复创建；成功后进入群信息或群聊，不出现人工审批步骤。创建失败保留表单；账号受限时说明原因。人数及创建配额仍待评审，不借取消审批默认无限制。

G02 建议首版仅文字消息。发送先显示“发送中”，持久化成功后确认，失败显示重试和删除本机失败消息。没有逐人已读承诺；可显示未读分隔线。收到消息时，用户位于底部才自动滚动，否则显示“有新消息”。退出再进入按上次读到的位置恢复，补取失败不清空已有可访问消息。

长按消息提供复制及举报；自己已送达消息的撤回首版暂不提供。消息输入超过上限显示字数与原因。消息发出后只清空已提交文本，新输入不因旧请求回包丢失。失去成员资格立即停用输入并清理不可访问内容。

G03 显示群介绍、成员（仅成员可见）、公告、免打扰、举报和退出。退出确认说明退出后不能查看群历史；重新加入不自动获得退出期间内容。群主可管理群信息、移除成员和发布公告，操作有确认和结果反馈；普通成员不看到管理按钮。没有入群审批入口。活动群和恋爱群继续遵循各自资格条件。

## 8. 恋爱配对

### L01 开通与声明

发现页恋爱入口先展示中文说明；游客点击“开启恋爱交友”先完成注册。登录用户进入声明页，复选框“我已年满 18 岁”默认未选，选择后才能继续。明确“这是年龄自我声明”，不显示“认证成功”。保存失败不进入恋爱资料列表，取消返回普通社区。

### L02 独立恋爱资料

建议必填：恋爱展示昵称、自我介绍、至少一张审核通过照片、交友目的；兴趣、地区及匹配偏好可选。需要展示年龄时另行确认出生信息收集范围，首版不凭勾选生成具体年龄。性别与偏好字段的选项、必填性待评审，不推断或自动公开。

填写时显示资料预览和范围：“仅向开启恋爱功能且满足权限的用户展示”。照片待审显示审核中，资料完成且照片通过才可进入候选推荐。关闭恋爱意愿后资料停止推荐，普通社区资料不受影响。

### L03/L04/L05 推荐、喜欢与匹配

推荐采用卡片列表，可打开详情；显示照片、简介、共同兴趣和大致地区。提供明确的“喜欢”“跳过”按钮，不强迫用户记忆滑动手势。点击喜欢后显示已喜欢，失败可以重试，不能伪显示匹配。

双向喜欢后展示匹配成功页，按钮为“开始聊天”和“继续浏览”；不自动发送开场白。恋爱私聊提供可选共同兴趣话题，用户修改后主动发送。恋爱资料入口未匹配时不开放恋爱私聊；普通公开主页的普通私聊独立开放，不要求恋爱匹配。

空推荐页提供调整兴趣/地区偏好；不显示虚构用户。不公开谁跳过了谁。拉黑、取消匹配、关闭恋爱或撤销声明后立即停止相关通信，历史是否保留遵循数据政策，不能继续显示可发送输入框。

设置提供“关闭恋爱展示”和“撤销年龄声明”，两者分开，确认说明对现有私聊的影响。未来需要正式核验时增加独立流程，旧自我声明不可显示为已核验。

## 9. 同城活动

E01 卡片显示标题、公开大致地区、日本时间、主题、人数状态及免费标签。筛选可选日期范围、地区和兴趣。活动满员仍可查看但报名禁用，首版不提供候补或付款。

E02 详情展示组织者、介绍、时间、粗略地点、名额、取消规则、报名截止及活动状态。具体集合地点仅已报名用户可见；示例地图不得精确暴露未公开地点。参加者名单仅授权成员可见，公开页只显示人数。

点击报名：游客先注册→补充必要昵称→E03 阅读规则并主动确认→提交。必须等待服务端成功才提示报名成功；超时查询报名状态，满员显示名额不足；成功提供“进入活动群”和“查看报名”。不自动获取通讯录或公开邮箱。

E04 可查看报名与活动状态。取消报名确认同时说明活动群资格将取消，成功后更新名额与群入口，失败保持报名状态。活动修改时间或地点后推送通知并在详情突出变更；重大变更的重新确认机制待评审。

E05 所有正常注册用户可发布活动，不需组织者预授权。字段为标题、主题、时间与截止、大致地区、仅报名可见的集合信息、人数、说明及取消规则。仅发布者编辑和取消本人活动，平台处理违规权限独立。建议发布前预览；已有人报名后修改时间、地点或规则需确认并通知，人数上限不能低于已报名人数。取消需填写原因并确认，禁止新报名、通知报名者、活动群转只读；具体修改取消细则仍待确认，消息仍按每条发送满一年删除。

## 10. 消息、我的与隐私

N01 聊天列表包含群聊、普通私聊和恋爱匹配私聊，以文字标签区分。显示群/联系人、更新时间、未读数；锁屏推送默认不含正文。互动通知包含回复、内容审核结果、群公告和活动变更，不提供入群申请审批通知。点通知重新检查目标权限，删除或失效显示不可用说明，不沿用通知中缓存正文。

C01 从普通公开主页“发消息”或有权查看的群成员资料进入，游客先注册。普通私聊不要求恋爱声明或匹配，复用文字聊天、重试、举报和拉黑；匿名游客名称不提供私聊目标。建议默认接受注册用户私聊，在设置中可关闭接收；关闭、拉黑或账号受限时显示无法发送。恋爱关闭不关闭普通私聊，普通页不展示恋爱资料或匹配标识。

游客消息入口不要求注册即可显示说明，但不提供跨设备提醒。自己帖子的回复可通过本机发布记录查看。游客推送通知首版暂不实现，待单独评审。

P01 游客显示“游客模式”、本机发布与草稿、邮箱注册入口；注册用户显示普通资料、我的发布、我的群、我的活动、恋爱状态。普通公开主页不显示邮箱、年龄声明、活动参加记录和恋爱偏好。首版关注功能暂不实现，不能展示无效按钮。

S01 包含通知设置、恋爱展示设置、屏蔽名单、内容与隐私说明、帮助、退出登录和删除账号。退出登录保留还是清除草稿需主动说明，共享设备建议清除账号缓存。删除账号先显示影响→邮箱确认→提交；即时撤销访问，显示删除处理状态，不承诺不受例外约束的即时彻底删除。

保留一年说明采用“聊天消息、留言板帖子及回复从发送或发布时间起保留一年，到期删除”。每条内容独立计时，新回复不延长旧内容，编辑不续期。内容到期使用“内容已不可用”占位并清理缓存；活跃账号不会因创建满一年自动删除，其他数据分类例外另行确定。

## 11. 举报、屏蔽与管理后台

R01 从帖子、回复、消息、资料或活动进入，携带目标 ID；选择诈骗、骚扰、垃圾广告、隐私泄露等理由，可填补充说明。游客可举报，提交后返回原处提示已受理，不立即宣称已删除。重复提交返回已有受理状态。

屏蔽需要登录（建议）；确认说明限制直接联系、隐藏对方群消息，但不能阻止对方查看公开帖子。群安全问题提供“举报并退出”分步操作，不把举报提交等同退群成功。

后台页面：登录与多因素验证、待审内容列表、举报详情、群与成员管理、活动管理、账号限制、任务失败列表、操作审计。详情显示必要上下文和可见范围；隐藏、删除、封禁需填写理由与确认，高影响操作采用角色限制。失败显示重试但不能重复执行成功的动作。年龄自我声明不在后台标成核验通过。

## 12. 通用状态与跨平台规范

| 状态 | 用户体验 |
|---|---|
| 初始加载 | 骨架或局部进度，不反复整页闪烁 |
| 没有内容 | 原因与可操作入口，无虚构内容 |
| 无网络 | 保留草稿和已有可访问内容，显示重试 |
| 操作超时 | 查询服务端结果，不鼓励重复创建 |
| 审核中/未通过 | 区分上传完成与公开发布，提供处理入口 |
| 429 限流 | 显示建议等待时间，保留编辑内容 |
| 登录过期 | 停止受限操作，重新登录后回原页 |
| 权限撤销 | 停用输入，清除不可见内容，返回安全入口 |
| 图片过期/删除 | 占位提示，不无限加载破损图片 |

iOS 使用安全区与系统返回习惯；Android 支持系统返回键，编辑有改动时执行草稿确认。聊天和回复输入栏随键盘移动；弹窗不遮挡确认按钮。支持系统字体缩放、屏幕阅读器、至少 44pt（iOS）/48dp（Android）的交互目标；状态不能只靠颜色表示。

时间按 Asia/Tokyo：列表可显示相对时间，活动明确日期、时刻和日本时间；跨年显示年份。昵称及中文长文本折行，支持日文地名，不截断重要操作名称。

视觉方向：浅色背景、清晰文字层级、温和蓝绿主色；恋爱主按钮采用鲜明粉红色 #D92370，白色文字需满足可读对比度，所有模块共用导航和组件。深色模式另行评审。

## 13. 关键验收场景

1. 全新安装不注册，浏览帖子、发布文字和图片回复，查看待审结果并管理本人内容。
2. 游客选图失败、离线、应用重启后恢复草稿，不产生重复上传或重复帖子。
3. 注册后回到原加入或报名入口；接续内容所有权但不自动公开账号关联。
4. 游客无法通过页面跳转访问群消息、恋爱资料或参加者名单。
5. 年龄框不预选，不勾选无法开通；界面不存在未经核验的认证标识。
6. 双方喜欢才出现私聊；取消匹配、撤销声明或拉黑后停止通信。
7. 并发最后一个活动名额只有一人报名成功，失败用户看到明确结果。
8. 审核不通过不公开图片；删帖、撤销权限和内容到期后不展示本地残留正文。
9. 退群、重新加入和报名取消符合历史访问规则，状态在不同设备保持一致。
10. 两端真机检查选图、键盘、返回、字体缩放、推送跳转和异常状态。
