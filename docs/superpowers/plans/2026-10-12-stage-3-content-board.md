# 第三阶段：留言板与图片审核实施计划

> **执行提示：** 按任务顺序逐项实施。每个代码任务先添加失败测试，再实现、运行检查、审查中文注释与差分，通过后单独本地提交。不得用本计划、健康检查或旧日志代替业务验收。

**目标：** 完成游客与注册用户公开留言板、图文回复、私有本机图片上传与处理、人工审核、举报、最小管理台，并接入内容即时到期过滤及异步清理。

**依据：** [第三阶段设计规格](../specs/2026-10-12-stage-3-content-board-design.md)、[阶段总计划](2026-10-03-phased-development-acceptance.md)、[数据库与 API 详细设计](../specs/2026-10-03-social-app-database-api-design.md)、[技术设计](../specs/2026-10-03-social-app-technical-design.md)、[UI 与交互设计](../specs/2026-10-03-social-app-ui-interaction-design.md)、[OpenAPI 合同](../../../packages/contracts/openapi.json)。本阶段规格中已确认的本机存储、人工审核规则优先于旧稿中 S3 已接入或待定的内容。

**架构：** Expo/React Native/TypeScript 手机端和 React 管理端；Java 21、Spring Boot、MyBatis、PostgreSQL API；独立 worker 执行可重试处理/清理任务。本机私有文件系统由媒体存储接口隔离，之后可加 S3 实现。媒体技术状态和内容审核状态分离。此阶段只由人工作发布决定，不接 AI。

**现有基础：** API 已有 auth、guest、profile、security；worker 只有骨架；admin 只有基础健康页；合同源为 packages/contracts/src/operations.cjs、schemas.cjs 和生成的 openapi.json；数据库有 V1-V3 迁移。现有初始设计已有帖子、媒体、举报、管理员和审核表。必须逐字段核对并复用现有内容；不改写 V1-V3，不重复建表。只有证明存在缺口时追加新迁移。

## 全局约束

- 范围仅包含普通公开留言板、图片、筛选、本人内容管理、举报、图片处理及人工审核台；排除群聊、活动、恋爱审核、私聊审核、AI、S3 实际接入和完整运营分析。
- 服务端执行文字限额：帖子标题/正文 60/2,000 个可见字符，回复 1,000；每帖/回复最多 9/3 张图。支持静态 JPEG/PNG/WebP，最多 5,000,000 bytes 和 20,000,000 解码像素；展示图最长边 1,920，不放大、目标不超 1 MB，移除 EXIF。
- 首次人工发布后计时一年；到期时 API 立即隐藏，worker 后续清理正文、图片和缓存。未绑定上传满 24 小时清理；待审超过 72 小时告警并保留，不自动驳回或删除。
- 待审内容和原图均不可公开。媒体技术处理 ready 不等于内容审核通过。所有下载须重新鉴权，不能暴露可枚举文件名或永久公开 URL。
- 游客沿用凭证证明所有权，账号沿用登录身份。服务端授权创建、查询、绑定、修改、删除及审核，不信任客户端 owner/state/path。
- 新增/修改代码须有附近简明中文注释，说明权限、规则、事务、边界；测试以中文标明场景和预期。每项代码变更运行本任务测试，失败修复重测。
- 当前 findings.md 的修改与 apps/mobile/.idea/ 未跟踪目录是已有无关内容，不纳入本阶段提交。

- 后端：在 backend/api/src/main/java/jp/youren/api/ 下增加 board、media、moderation、reports、admin 中必要的 controller/service/DTO；复用 auth/guest/security。持久化增补 backend/database Mapper/XML；worker 位于 backend/worker/src/main/java/jp/youren/worker/。
- 本机媒体：抽象 StoragePort 并实现 LocalFileStorage；通过 YOUREN_MEDIA_ROOT 配置私有绝对路径；开发数据目录加入 .gitignore，不提交本机图像、秘密或用户数据。
- 客户端：扩展 apps/mobile/src/api、screens、components、本人内容入口与测试；扩展 apps/admin/src/api、管理员会话、审核/举报队列及测试。不要重写现有登录和游客状态。
- 文档：增量更新 contracts/API/worker/mobile/admin README（存在时），新建 docs/development/stage-3-acceptance.md；路线图只根据实际验收更新。
- 开工时确认活动源合同及现有 V1-V3 的帖子、媒体、报告、admin、moderation、outbox、幂等表；记录可复用字段和缺口。仅缺字段/约束时添加 V4 或后续迁移及中文 SQL 注释。复核技术设计中 S3 存储现状，写明本地阶段和未来迁移边界。
- 确认图片解码依赖及资源边界、MFA 方式和密钥注入、管理员一次性初始化安全。建立合同、数据库/API、mobile/admin 基线，记录提交号、命令和已有失败；不可把旧运行日志当成本次验证。

## 任务1：合同、数据模型与本机开发配置

**范围：** 合同源、必要的 Mapper/迁移、OpenAPI、技术/数据库文档及本机路径说明。

- [ ] 为 GET /posts、详情/回复、帖子与回复增删改、/me/content、媒体上传/完成/状态/删除、举报、管理待审/举报、管理员登录/MFA 和管理审核动作编写合同断言。
- [ ] 在合同中约定权限、内容状态、游标、限额、幂等键、期望版本、错误码；公开 DTO 不得含 owner principal、邮箱、对象键或原图地址。
- [ ] 对照已有迁移逐字段审计帖子、评论、媒体变体、举报、管理员会话、审核动作、outbox、幂等数据。符合设计就复用；仅缺失时新增迁移，验证空库和 V3 升级，旧迁移校验和不变。
- [ ] 明确 YOUREN_MEDIA_ROOT 为本机私有绝对路径；默认开发数据不得进入 Git 或静态目录，部署无公用 URL；同步技术设计与数据库/API媒体合同，消除本阶段 S3 已接入的误导。
- [ ] 运行合同测试、生成文件一致性检查和 backend/database verify。差分与中文说明审查后提交一笔具体本地提交。

## 任务2：私有存储、上传意向与图片处理

**范围：** StoragePort/LocalFileStorage、媒体 API/service、处理器、Mapper 与集成测试。

- [ ] 先测试路径穿越、目录逃逸、伪造对象键、未授权读取、配置缺失安全失败；验证对象键随机且不由用户控制，根目录不对静态 HTTP 暴露。
- [ ] 测上传意向归属、过期、用途、字节上限、重复 complete 幂等、另一身份完成失败、ready 前禁止绑定及未绑定 24 小时清理。
- [ ] 用真实固定图片和坏样本覆盖 JPEG/PNG/WebP、伪扩展名/MIME、动画/损坏图、5,000,000 bytes 与 20,000,000 像素边界、EXIF 移除、展示图不放大/长边限制、重编码失败及解码内存/时间限制。
- [ ] 实现本机媒体端口，业务只存对象键；原图、展示图、临时文件分区，失败清理半成品；完成处理后只标记技术 ready，不能自动批准内容。
- [ ] 运行新增图片及 PostgreSQL 集成测试和 backend api verify。确认本地媒体目录被忽略，审查中文注释与差分，通过后本地提交。

## 任务3：留言板 API、状态与访问权限

**范围：** board controller/service/DTO、查询与 Mapper、媒体原子绑定、合同/API集成测试。

- [ ] 覆盖游客/账号创建、本人编辑/删除、越权拒绝；帖子 pending 不出现在公开列表/详情，回复必须隶属公开且未到期帖子。
- [ ] 覆盖标题/正文/回复的 Unicode grapheme 与 NFC、空白、纯图回复、图片数量、无效筛选、跨帖回复引用、跨 owner 绑定、重复绑定和幂等提交。
- [ ] 多图绑定和内容提交全有或全无；不接受客户端指定 owner、公开状态、publishedAt、expiresAt。拒绝时没有半成品连接。
- [ ] 实现地区/兴趣筛选、稳定排序/游标分页、本人内容状态查询、被驳回编辑后重新 pending、版本冲突和删除立即不可见。DTO 只输出已审核展示图和允许公开的作者字段。
- [ ] 首次人工通过才记录 publishedAt 和一年 expiresAt；隐藏恢复沿用原期限。所有公开查询和媒体鉴权按服务端 now >= expiresAt 即过滤。
- [ ] 运行 backend api/database verify 与合同生成检查，验证 PostgreSQL集成和所有权边界。审查后本地提交。

## 任务4：人工审核、举报与首管理员初始化

**范围：** moderation/reports/admin API、角色、审计、单次初始化命令、独立管理会话与测试。

- [ ] 测无效/缺失 MFA、无管理员、禁用账号、普通用户 token 访问后台均拒绝；只读审计员不得操作内容。
- [ ] 实现一次性本机管理员初始化：无默认账户/口令，交互创建凭据并配置 MFA；重复初始化安全失败；秘密不进入参数、日志、异常或仓库。后续账号只通过授权流程创建。
- [ ] 管理身份、令牌、session 与普通用户分离；MFA 密钥加密保存，密钥从环境注入。记录如何本机首次初始化及紧急恢复的运维说明。
- [ ] 测人工通过、驳回、编辑重提、隐藏、恢复、删除、无理由、旧版本、并发决定及幂等重试；保存审核主体、理由、目标版本及审计。仅 HumanModerationProvider，不能把图片检测结果当发布决定。
- [ ] 测游客和账号举报有权查看的帖子/回复、reason code、说明限长、幂等重复、举报信息隔离；举报结案不隐式删除内容，游客不能举报私有对象。
- [ ] 实现 pending 超 72 小时告警及去重，内容保留并人工处置。运行 API/database verify、角色与脱敏测试；差分审查后本地提交。

## 任务5：移动端帖子、图片与本人内容

**范围：** mobile 的留言板/媒体/举报 API、列表、详情、编辑器、本人内容与测试。

- [ ] 先测筛选/分页、空状态、待审/驳回/隐藏/过期作者状态、权限错误、重试及网络失败；不得渲染未授权缓存。
- [ ] 测选图错误、格式/大小、图片数、上传/处理/提交三阶段、重复点击、超时查询和草稿保留。超时先核对状态，不能盲目重复创建。
- [ ] 实现游客与账号现有会话接入；标明待审而非公开；通过后公开，驳回可编辑重提，本人可删除，用户可举报当前可见内容。上传状态和审核状态分开呈现。
- [ ] 实现地区/兴趣筛选及稳定翻页；允许本人查看有效回复而不泄漏已到期父帖正文。
- [ ] Android 模拟器实操游客发帖/图文回复、非法图拒绝、审核状态、筛选、重提、删除、举报及断网恢复。iOS 原生验收仍按之前决定延期，不能记通过。
- [ ] 运行 mobile 测试、类型检查、构建及需要的 Expo 导出检查；审查界面和中文注释，差分通过后本地提交。

## 任务6：管理端审核和举报工作台

**范围：** admin 独立认证/MFA、队列/详情/动作表单、权限组件、Vitest/Playwright。

- [ ] 测登录与 MFA 错误、过期会话、角色越权、空队列、等待排序、72 小时告警、API 故障和恢复。后端权限为权威，不能只靠隐藏按钮。
- [ ] 实现与手机/普通用户隔离的管理会话；待审、举报、已处理队列；详情只展示必要上下文和展示图，不默认提供原图，不暴露游客凭证、邮箱或磁盘路径。
- [ ] 通过、驳回、隐藏、恢复、删除和举报结案分开操作；状态变更需理由、确认、expectedVersion 与幂等键。版本冲突要求重新加载，不覆盖他人操作。
- [ ] >72 小时项目显示提醒并保持待审，不显示自动驳回倒计时。
- [ ] 运行 admin 单测、类型检查、构建及必要的 Playwright 流程；实际打开管理页面验证展示和操作。审查差分、中文注释及状态后本地提交。

## 任务7：到期和孤儿清理、全链路验收

**范围：** worker job、缓存失效、清理测试、运行文档、阶段验收记录和路线状态。

- [ ] 测 now < expiresAt、now = expiresAt、UTC 跨年/闰日、编辑/新回复不续期、隐藏恢复不续期、父帖占位及回复独立期限。
- [ ] 实现分批、可重试、幂等清理：先使内容和媒体不可见，再删除正文、变体、原图、缓存并清理关系；失败任务保留必要元数据和告警，不重新公开内容。
- [ ] 实现 24 小时未绑定媒体清理和 72 小时待审告警，任务去重。待审条目不进入发布内容的一年到期清理。
- [ ] 测 worker 停止/重启、部分对象删除、任务重试；确认过期内容即使 worker 未运行也无法通过 API/旧地址访问。
- [ ] 更新本机路径配置、初始化管理员、API/worker/admin/Metro 启动步骤、备份/清理、安全说明和测试命令；明确本阶段不需要 S3 或 AI。
- [ ] 全链路：数据库迁移、PostgreSQL/Redis、API、worker、admin、Android模拟器；游客上传→处理→人工审核→公开→筛选/回复/举报→本人删除。并验证非法图片、待审不可见、越权、驳回重提、到期及清理失败恢复。
- [ ] 运行 npm run check、npm run check:engineering、Java clean verify、mobile/admin 测试与构建及浏览器操作验收。记录具体命令/版本/结果/未做项；检查 Markdown 引用、合同生成、秘密扫描、中文注释与 git diff --check。

## 阶段退出条件

- 游客和账号完整完成本人图文发布、人工审核、公开展示、筛选、回复、举报、本人删除；越权被拒绝。
- 本机图片不公开裸露；处理边界与 EXIF 处理经过测试；媒体 ready 和内容审核决定相互独立。
- 管理角色隔离、审计和首管理员单次初始化有效；72 小时告警不自动处置；本阶段无 AI/S3 接入误报。
- 到期时立即过滤，后台清理可恢复且幂等；运行文档、验收记录、测试与差分审查完成。
- 未运行的 iOS 原生、生产供应商或其他设备验收明确标记未完成，不用模拟器或测试替身替代。
