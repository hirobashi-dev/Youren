# 第三阶段数据模型审计

审计依据：`V1__initial.sql`、`V2__identity_credentials.sql`、`V3__profile_drafts.sql` 与冻结的 V1 摘要。V1-V3 未修改，V1 摘要保持 `b82f713c348c1b7bbd3c3ee1c50029c0904d189a799c4cea02274c02ce8b3bec`。

## 可复用结构

| 业务边界 | 现有表和字段 | 结论 |
|---|---|---|
| 帖子与回复 | `posts`、`comments`：作者主体、状态、正文、版本、发布时间、到期时间和删除时间；帖子另含地区、分类，回复有父帖及同帖引用字段 | 覆盖本人权限判断、待审/公开/驳回/隐藏状态、并发编辑和一年期限；查询仍须按服务端当前时间过滤 |
| 媒体与绑定 | `media_assets`：主体、用途、随机对象键、技术状态、MIME、字节数、像素尺寸、摘要、上传期限与孤儿清理时间；`media_variants` 存变体对象键和尺寸；`post_media`、`comment_media` 存位置关系 | 覆盖本机私有文件的对象元数据和帖子/回复图片绑定；对象键只在后端使用。`media_assets.status='approved'` 是现有技术处理状态，API 文案明确其不代表内容人工审核通过 |
| 举报 | `reports`：举报主体、目标类型/目标外键、理由、说明、状态、结案时间和保留时间 | 原字段够表达举报，但缺少并发结案版本；V4 添加 `version`，旧行默认为 1 |
| 管理身份与审计 | `admin_accounts`：登录名、密码摘要、状态、角色、加密 MFA 密钥和认证版本；`admin_sessions`：令牌摘要、MFA 验证、过期和撤销时间；`moderation_actions`：目标、管理员、动作、理由和保留时间 | 隔离管理员登录和审计基础已存在；V1 未保存决定时审核员查看的对象版本，V4 增加 `expected_version`，迁移前记录保留 NULL。`pendingSince` 由内容初次创建时间或最近一次进入待审时维护的 `updated_at` 派生，超时标记由服务端计算 |
| 任务和重试 | `outbox`：任务类型、聚合对象、状态、尝试次数、下次执行、租约、错误码和去重键；`idempotency_records`：操作者、方法、路由、幂等键、请求摘要、结果资源/状态和期限 | 满足可靠任务和写请求幂等记录的基础；业务服务仍须在同一事务写业务数据和 outbox |

## 迁移决定

V1-V3 已有本阶段主要实体与关系，不新增重复表。唯一字段缺口是举报结案的乐观锁版本和审核决定的已审阅版本，因此新增 `V4__versioned_content_review.sql`。迁移仅增加字段与正数检查，不改旧迁移、不触碰已存正文或秘密。V4 集成测试覆盖空库升级、历史迁移顺序和字段约束；V1 schema 指纹测试继续保护原基线。

第三阶段文件根目录通过 `YOUREN_MEDIA_ROOT` 配置为本机私有绝对路径。目录不得处于 Web 静态根目录或 Git 跟踪目录；数据库只保存随机对象键，不保存用户传入路径。未来 S3 需要新增存储适配和文件复制流程，本阶段不创建云资源。
